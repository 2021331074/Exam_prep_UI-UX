EXAM PREP UI/UX DEMO
====================

OVERVIEW
--------
A browser-based exam-preparation interface with sample exams and demo
questions. It is a front-end demo; sample questions are for practice and
may not match official exam papers or current syllabuses.

EXAM CATEGORIES
---------------
The demo may include exams such as:
- Bangladesh national exams: HSC, SSC, and admission tests
- ITEE, including ITEE IP
- IELTS, TOEFL, SAT, GRE, GMAT, and other international exams

WHAT YOU NEED
-------------
- A modern web browser, such as Microsoft Edge, Chrome, or Firefox
- The project files, including index.html

No package installation or build step is needed for the basic demo.

RUN ON WINDOWS
--------------
Option 1: Open directly
1. Open the project folder.
2. Double-click index.html.

Option 2: Run a local server with Python
1. Open PowerShell in the project folder.
2. Run:

   py -m http.server 5500

3. Open this address in your browser:

   http://localhost:5500

If the command `py` is not recognized, open index.html directly or use
the VS Code Live Server extension.

EDITING THE DEMO
----------------
To change the interface or sample questions, edit the relevant HTML,
CSS, or JavaScript in the project files. Keep a backup before making
large changes.

NOTES
-----
- This is a demo interface, not an official exam resource.
- Check official exam providers and education-board materials for
  current formats, rules, and syllabuses.
- If the page does not load, confirm that index.html is in the folder
  you opened and check the browser console for errors.
